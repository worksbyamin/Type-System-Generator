# Type System Generator

A powerful, visual web application designed to create, preview, and export comprehensive typography systems and design tokens. This tool bridges the gap between typography design and code, providing an advanced visual interface for granular type calibration.

*Note: This project was mostly "vibe coded" because I was in need of a better typescale generator with local and variable font support that was free and more advanced than what was currently available.*

## Features

- **Interactive Specimen Preview**: Visually tune your typography system in real-time across both Light and Dark modes.
- **Local & Variable Fonts**: Granular control over variable font axes (Weight, Width, Slant, Optical Size, etc.) and full support for testing local system fonts.
- **RTL & LTR Support**: Built-in support for multiple languages including English (LTR) and Farsi (RTL) type specimens.
- **Modular Scale**: Generate harmonious typography scales based on mathematical baseline ratios.
- **Fine-grained Control**: Adjust leading (line-height), tracking (letter-spacing), and font weights for every semantic typography level (H1-H6, Body, Caption, etc.).
- **Code Generation**: Instantly export your configured type system into ready-to-use CSS/code.
